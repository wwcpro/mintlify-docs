title: Save Search
description: Bookmark a search result as a named list for later use.

See the full [Saved Lists guide](/aircraft/saved-lists) for complete documentation.

## Quick reference

1. Run a search → results appear
2. Click ⚡ → **Save Search**
3. Type a name → Enter
4. Access later from **Saved Lists** in the sidebar

Saved lists store the **exact aircraft IDs**, not the query. Reloading always returns the same aircraft (with current JetNet data).
