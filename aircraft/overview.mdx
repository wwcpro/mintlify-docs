## What is Aircraft Data?

The Aircraft Data section gives you access to the full JetNet database — over **80,000 aircraft** — filtered automatically to your franchise territory.

## Territory filtering

When you're signed in as a Franchisee, every AI search automatically restricts results to aircraft based at **your territory airports**. You don't need to add location filters.

Your territory airports are shown in the top-right corner of the Aircraft Data page.

<Tip>
  If you want to search outside your territory (for prospect research), contact your admin to temporarily adjust your airport list.
</Tip>

## What data comes from JetNet?

Each aircraft record includes:

| Field | Description |
|-------|-------------|
| Tail # (regnbr) | FAA registration number |
| Make / Model | Manufacturer and model name |
| Year | Year delivered or manufactured |
| Base Airport | IATA/ICAO code where the aircraft is based |
| Owner | Company name, first/last name, email, phone |
| Operator | Day-to-day operator details |
| For Sale | Whether the aircraft is listed (Y/N) |
| Asking Price | Listing price (may show POR) |
| Airframe Type | FixedWing or Rotary |
| Category/Size | Light Jet, Mid-Size Jet, Turboprop, etc. |

## Navigation tabs

The Aircraft Data page has two tabs:

- **Aircraft** — AI search + filter chips
- **Airports** — Map view of your territory airports with departures/arrivals
