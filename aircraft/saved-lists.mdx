## What are Saved Lists?

A Saved List stores the **exact aircraft IDs** from a search result. When you reload a saved list, the platform fetches those specific aircraft directly — no AI re-query, no results that have changed.

This is different from saving a search query. A saved list is a **snapshot** of aircraft at the time you saved it.

## Saving a list

<Steps>
  <Step title="Run a search and review results">
    Use the AI search bar to find the aircraft you want to save. You can also [Refine](/aircraft/refine) first to narrow the results.
  </Step>
  <Step title="Open the action panel">
    Click the **⚡ lightning bolt** in the bottom-right corner.
  </Step>
  <Step title="Click Save Search">
    Click **Save Search** in the panel.

    A name input appears inline in the results header.
  </Step>
  <Step title="Name your list">
    Type a descriptive name, then press Enter or click **Save**:
    ```
    Texas Jets For Sale - June 2026
    Cessnas at ARR
    Heavy Jets Under 5M
    ```
  </Step>
</Steps>

<Check>
  You'll see a toast: **"List saved — 48 aircraft"**
</Check>

## Viewing saved lists

Go to **Saved Lists** in the left sidebar (under Platform).

Each list shows:
- List name
- Date saved
- Number of aircraft

## Loading a saved list

Click any list in the Saved Lists page. You're taken directly to the Aircraft Data page showing those exact aircraft — no search required.

The header shows:
```
[List name]
42 saved aircraft · exact list, no re-query
```

An **← All Saved Lists** link lets you return to your list collection.

## When to use Saved Lists vs re-searching

| Scenario | Use |
|----------|-----|
| I want the same aircraft I found last week | Saved List |
| I want fresh data for today's market | New search |
| I want to share an exact set with a colleague | Saved List |
| I'm doing ongoing market research | New search |

<Warning>
  Saved lists are a snapshot. If an aircraft's ownership or sale status changes in JetNet, the saved list still returns the original aircraft — it just shows their current data when loaded.
</Warning>
