## What are tags?

Tags are free-form labels you put on prospects. They're useful for segmentation that doesn't fit the standard stage/source fields:

- Priority tiers: `Hot Lead`, `VIP`, `Needs Follow-up`
- Aircraft type interest: `Turboprop`, `Heavy Jet`
- Territory notes: `Trade Show`, `Referral`
- Campaign tracking: `Email Series 1`, `Fall Promo`

A prospect can have multiple tags. Tags are shared across your whole franchise account.

## Adding a tag in list view

<Steps>
  <Step title="Switch to list view">
    Click the list icon (top right of the board).
  </Step>
  <Step title="Click the + on a row">
    Each prospect row has a **+** button in the tags column. Click it.
  </Step>
  <Step title="Type and confirm">
    Type the tag name and press **Enter** (or click away). The tag appears immediately on the row.
  </Step>
</Steps>

## Adding a tag via bulk actions

Select multiple prospects and use the **Tag** option from the bulk actions menu. See [Bulk Actions](/crm/bulk-actions).

## Removing a tag

Open the prospect detail and edit the tags in the Edit Contact modal.

## Filtering by tag

- **Filter bar**: Click Filters → Tag dropdown → select tag
- **List view**: Click any tag chip on a row to instantly filter the whole list to that tag

## Tags on board cards

Board view cards show up to 3 tags as amber pills. If a prospect has more than 3, the first 3 display and the rest are visible on the detail page.
